# Portfolio 4: NoSQL and Advanced Data Models
 ## Course Details
 - Course Code: MIT 8103
- Course Title: Advanced Database Systems
- Case Study: Library Management System
  ## Introduction
This portfolio investigates the use of document-based data models and NoSQL databases for library information management.
## Goals
-Recognize the principles of NoSQL databases.
-Create a database model based on documents.
-Use MongoDB to create a NoSQL database.
-Keep and access library materials.
-Describe why NoSQL databases are appropriate.
## Instruments
-MongoDB
-MongoDB Compass 
## Useful Application
This portfolio will show how MongoDB documents may be used to represent library data, such as books and their properties.
Sample documents, query results, and screenshots will be provided
## Anticipated Results
This portfolio will show how flexible data storage and retrieval in a library management system can be supported by NoSQL databases.
