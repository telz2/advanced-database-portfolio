#Portfolio 5: Exercise with Distributed and Cloud Databases
 ## Course Information
- Course Code: MIT 8103
- Course Title: Advanced Database Systems
- Case Study: Library Management System
 ## Introduction
The application of distributed and cloud database principles to a library management system is examined in this portfolio.
## Goals
-Recognize distributed database systems.
-Describe database replication.
- Explore database sharding.
-Analyze the consistency and availability of databases
-Explain or illustrate the deployment of cloud databases.
# Tools
-MongoDB Atlas
-MongoDB Compass 
## Practical Implementation
This portfolio will examine the advantages of cloud database technology for a library management system.
Evidence of any practical cloud database setup, along with explanations of replication, sharding, availability, and consistency will be included
## Expected Outcomes
This portfolio will show that you understand how cloud and distributed database systems can improve availability, scalability, and accuracy.
