# Portfolio 3: Concurrency and Transactions 
##  Course Code: MIT 8103
- Course Title: Advanced Database Systems
- Case Study
Study: Library Management System
 ## Overview
This portfolio shows how concurrency control and database transactions are utilized in a library management system to ensure data accuracy, consistency, and dependability.
## Goals
-Demonstrate database transactions.
-Execute ROLLBACK and COMMIT procedures.
-Examine the degrees of transaction isolation.
-Exhibit problems with concurrency.
-Utilize techniques for concurrency control.
## Tools
-MySQL Server
-MySQL Workbench
## Practical Application
This folder will contain SQL scripts and pictures that illustrate concurrency control and transaction management.
## Anticipated Results
This portfolio will show how database integrity is maintained through transactions when multiple users access or modify library records
